- **Ρητός πίνακας CON-01 Q2 ↔ econ4:** αναδρομικά MAE 9,9 έναντι 12,3 της ομοιόμορφης.

## 6. Πώς ενεργοποιούνται οι νέες εκδόσεις

```bash

node_modules/.bin/tsx scripts/synthetic-lab/viewscope/run_study.ts --plan <μελέτη.json> --n 500 \
   --org "<φορέας>" --fieldwork-start <ημερομηνία> --published-waves --core --core-links links.json
```

Χωρίς τις σημαίες, οι υπάρχοντες μηχανισμοί λειτουργούν ακριβώς όπως πριν.
