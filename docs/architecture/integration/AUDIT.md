Διάγνωση των 37 ερωτήσεων του Κωτσόβολου στο Lab (autolink / IQGE / βαθμίδες): καμία ερώτηση με βαθμίδα ≤ 4 χωρίς αποχή. Τρεις αντιστοιχίζονται σε άγκυρες (econ4 / polint4 / believer) ως πειραματικές (βαθμίδα 4, expectedMAE 14,13), αλλά δεν αφορούν το ερωτηματολόγιο.

## 2. Κενά που έπρεπε να κλείσουν

1. Δύο ξεχωριστές ταυτότητες ερωτώμενου (Lab persona ≠ ASE profile).
2. Το ASE δεν έβλεπε εμπειρικές τιμές· το Lab δεν έβλεπε το ερωτηματολόγιο του ASE.
3. Η αυτόματη αντιστοίχιση λέξεων αντιμετωπιζόταν ως τεκμηρίωση (ψευδείς ταυτίσεις, π.χ. «πόσο» → «ποσό»).
4. Γενικοί δείκτες κινδύνευαν να γίνουν πιθανότητες για ερωτήσεις μάρκας.
5. Προεπιλεγμένο βάρος μείξης AI–δεδομένων (`hybrid_weight: 0.5`) χωρίς επικύρωση.
6. Κανένα διεθνές επίπεδο και καμία επικύρωση μεταφοράς μεταξύ χωρών.
7. Η ετικέτα «ΣΥΝΘΕΤΙΚΗ ΠΡΟΣΟΜΟΙΩΣΗ» δεν υπήρχε σε όλες τις εξόδους (CSV, εσωτερικά αρχεία).

## 3. Περιορισμοί περιβάλλοντος

| Πόρος | Τιμή |
|---|---|
| Δίσκος | ~6 GB ελεύθερα (85% χρήση) |
| Μνήμη / πυρήνες | 15 GB / 4 |
| AI | μόνο η συνεδρία Claude Code μέσω του `claude_session` (αρχεία)· χωρίς API key, χωρίς χρεώσεις ανά κλήση |
| Δίκτυο | Eurostat API διαθέσιμο· ESS/WVS/ICPSR απαιτούν εγγραφή/αποδοχή όρων → δεν γίνεται αυτόματα |
| Python | χωρίς pytest/εγκαταστάσεις· runner `research-engine/tests/run_tests.py` |

## 4. Στρατηγική (αναστρέψιμη)

- Καμία ανακατασκευή: το Lab καλείται μέσω γέφυρας (`scripts/synthetic-lab/bridge/lab_bridge.ts`) που χρησιμοποιεί **μόνο υπάρχουσες συναρτήσεις** (`generateAnchors`, `suggestLink`, `prepareQuestion`, `classifyEvidence`, `answerPersona`).
- Το ASE παραμένει η ενιαία πηγή αλήθειας για τον ερωτώμενο· το Lab επιστρέφει αποτελέσματα με τα IDs του ASE.
- Νέα δεδομένα (ευρετήριο lake, λήψεις Eurostat, επικυρώσεις) γράφονται στο gitignored `.synthetic-lab-data/ase/`· τίποτα δεν γράφεται μέσα στο lake.
- Κάθε βήμα σε ξεχωριστό commit (`e67077b`, `f1c71c7`, `a79daf7` και επόμενα).
