# Greek Research Data Lake (2012–2026)

Αποθήκη ερευνών για την Ελλάδα που τροφοδοτεί με **εμπειρικές κατανομές** το Synthetic Research Lab.
Χτίζεται από ένα επανεκκινήσιμο Python pipeline (`scripts/synthetic-lab/lake/`) και διαβάζεται από το
simulation engine μέσω `lib/synthetic-lab/data/lake.ts`.

> Τα δεδομένα του lake (βάση SQLite, πρωτότυπα αρχεία, εξαγωγές) **δεν μπαίνουν ποτέ στο repo**. Ζουν στο
> `.synthetic-lab-data/lake/` (gitignored) ή στο `$SYNTHETIC_LAB_LAKE_DIR`. Το `check-data` το ελέγχει.
> Όλοι οι αριθμοί κάλυψης βγαίνουν από τη βάση με `python -m lake.pipeline report`. Κανένας αριθμός δεν γράφεται με το χέρι.

## 1. Αρχιτεκτονική

```
πηγές ──► connectors (discover) ──► ουρά εργασιών (retry/backoff, checkpoints)
                                        │
                                        ▼
              λήψη (sha256, raw/) ──► parsing ──► μεταβλητές + κατανομές ──► έλεγχοι ──► export ──► engine
                                                                                              │
                         coverage_report (από τη βάση) ◄──────────────────────────────────────┘
```

| Αρχείο | Ρόλος |
|---|---|
| `lake/db.py` | Σχήμα SQLite (WAL), καταστάσεις, ουρά, checkpoints, συμβάντα |
| `lake/net.py` | HTTP με επαναπροσπάθειες, εκθετική αναμονή, `Retry-After`, ρυθμό ανά host |
| `lake/topics.py` | 25 θεματικές περιοχές, συνάφεια με Ελλάδα/έρευνα, άδειες, κλειδιά διπλοτύπων, σκορ ποιότητας |
| `lake/sources.py` | Registry πηγών (Deliverable A) + έλεγχος προσβασιμότητας |
| `lake/eurostat.py` | Όλα τα σύνολα Eurostat με γεωγραφία EL από το 2012, με διασπάσεις φύλου, ηλικίας, μόρφωσης και εισοδήματος |
| `lake/eurobarometer.py` | Eurobarometer (Standard, Special, Flash) από το data.europa.eu: Volume A (στήλη EL) και Volume C (διασπάσεις για την Ελλάδα) |
| `lake/worldbank.py` | Global Findex (Gallup World Poll), Ελλάδα 2011–2024, με διασπάσεις |
| `lake/repos.py` + `lake/parse.py` | Zenodo, Figshare, Harvard Dataverse, DataverseNL: λήψη επιτρεπτών αρχείων (CSV/XLSX/SAV/DTA/ODS/ZIP), ανάλυση μικροδεδομένων |
| `lake/catalogs.py` | CESSDA, OpenAIRE, Crossref: μεταδεδομένα, πρόσβαση και διπλότυπα μεταξύ αποθετηρίων |
| `lake/existing.py` | Τα σύνολα που ήδη χρησιμοποιεί το Lab (NORAYA, Eurostat ΤΠΕ/SILC, BCS, CES, HBS, GLOPOP-S, διαΝΕΟσις), ως INTEGRATED |
| `lake/export.py` | Εξαγωγή για το engine (Deliverables D/E/F) |
| `lake/report.py` | Αναφορά κάλυψης (Deliverable I) |
| `lake/monitor.py` | Παρακολούθηση νέων εκδόσεων/ερευνών (επαυξητική ενημέρωση, change log στα `events`) |
| `lake/run_all.sh` | Πλήρης συλλογή σε παράλληλες λωρίδες |

## 2. Καταστάσεις και επίπεδα τεκμηρίωσης

Καταστάσεις: `DISCOVERED → VERIFIED → DOWNLOADED → PARSED → VALIDATED → INTEGRATED`, και επιπλέον `RESTRICTED` και `FAILED`.
Μια κατάσταση δεν υποβαθμίζεται ποτέ, εκτός από μετάβαση σε `FAILED` ή `RESTRICTED`.

- **VERIFIED**: τα μεταδεδομένα επαληθεύτηκαν, χωρίς μηχαναγνώσιμα δεδομένα ή χωρίς ελληνική στήλη. Τα διπλότυπα μένουν σε αυτή την κατάσταση, με σύνδεσμο προς το πρωτότυπο.
- **RESTRICTED**: η πρόσβαση απαιτεί εγγραφή ή συμφωνητικό (GESIS, ESS, EVS/WVS, SHARE, αρχεία CESSDA). Καταγράφεται χωρίς λήψη.
- **INTEGRATED**: εξήχθη στο engine, ή είναι σύνολο που ήδη χρησιμοποιεί το Lab.

| Επίπεδο | Σημασία | Παράδειγμα |
|---|---|---|
| A | Πρωτογενή μικροδεδομένα | Αρχεία ερευνών σε αποθετήρια, διαΝΕΟσις |
| B | Λεπτομερή aggregates | Eurostat, πίνακες Eurobarometer, Findex |
| C | Δημοσιευμένα ευρήματα | Έρευνες χωρίς μηχαναγνώσιμους πίνακες |
| D | Περιορισμένη τεκμηρίωση | Εγγραφές καταλόγου (CESSDA/OpenAIRE/Crossref) |

## 3. Σχήμα βάσης (`lake.sqlite`)

`sources`, `studies` (πλήρη μεταδεδομένα: φορέας, έτη πεδίου, n, πληθυσμός, δειγματοληψία, αντιπροσωπευτικότητα,
βάρη, URL/DOI, άδεια, περιορισμοί, επίπεδο, κατάσταση, θέματα, σκορ ποιότητας, κλειδί/σύνδεσμος διπλοτύπου),
`files` (sha256, μέγεθος, έκδοση), `variables` (ερώτηση, επιλογές, ετικέτες τιμών), `distributions`
(επιλογή × ομάδα × κύμα, n, σταθμισμένο), `agg_cells` (πρωτογενή κελιά Eurostat), `queue`, `events`, `checkpoints`.

## 4. Έλεγχοι διαρροής και ποιότητας

- **Διπλότυπα**: ίδιο DOI, ίδιο κύμα Eurobarometer (π.χ. εγγραφή GESIS/CESSDA), ίδιος κανονικοποιημένος τίτλος και έτος σε άλλη πηγή. Τα διπλότυπα δεν εξάγονται.
- **Κύματα**: κάθε κατανομή φέρει το έτος συλλογής της. Τα κύματα δεν συγχωνεύονται.
- **Ασύμβατες κατηγορίες**: οι ομάδες κανονικοποιούνται μόνο όταν η αντιστοίχιση είναι ρητή:
  - ηλικία: Age-7 → ζώνες GLOPOP· οι 65–74 και 75+ ενώνονται με σταθμισμένο μέσο με βάση τις βάσεις δείγματος· οι Age-4 μένουν ξεχωριστή διάσταση (`age_group4`);
  - μόρφωση: ISCED ή επίπεδο διπλώματος → low/medium/high· η «ηλικία ολοκλήρωσης σπουδών» χρησιμοποιείται μόνο ως proxy, με σημείωση.
- **Βάρη**: οι πίνακες Eurobarometer είναι ήδη σταθμισμένοι. Στα μικροδεδομένα εντοπίζεται μεταβλητή βάρους· αν δεν υπάρχει, η κατανομή σημειώνεται ως μη σταθμισμένη.
- **Ελλείπουσες τιμές**: κελιά με n<10 δεν εξάγονται. Τα «Δεν ξέρω/Άρνηση» μένουν ως επιλογές και σημειώνονται.
- **Σφάλματα πηγής**: γραμμή «Δεν ξέρω» που αντιγράφει την τιμή άλλης επιλογής αφαιρείται.
- **Κωδικοποιήσεις**: UTF-8, cp1253 και latin-1 με αυτόματη αναγνώριση. Ετικέτες τιμών SPSS/Stata.
- **Διατύπωση**: διατηρείται η πρωτότυπη (αγγλική) διατύπωση της πηγής.
- **Εκδόσεις**: sha256 και ημερομηνία ανά αρχείο, χρονοσφραγίδα ενημέρωσης ανά μελέτη, πλήρες ημερολόγιο συμβάντων.
- **Αποκλεισμοί στην εξαγωγή**:
  - δείγματα επιχειρήσεων (B2B);
  - δείκτες Eurostat που δεν είναι «ποσοστό ατόμων ή νοικοκυριών» (π.χ. % ΑΕΠ, % αποδοχών);
  - ερωτήσεις ψήφου ή κομματικής προτίμησης (το Lab δεν μοντελοποιεί εκλογική συμπεριφορά).
- **Προσωπικά δεδομένα**: από τα μικροδεδομένα δεν εξάγονται ποτέ στήλες ταυτοποίησης ή ελεύθερου κειμένου.

## 5. Ενσωμάτωση στην προσομοίωση

**Ανάκτηση** (`searchLake`, API `GET /api/synthetic-lab/lake?q=…&year=…&holdout=…`):
- Αναζητά σε ερωτήσεις, επιλογές, μεταβλητές και τίτλους μελετών.
- Διαθέτει ελληνο-αγγλικό λεξικό θεμάτων, γιατί οι πηγές είναι στα αγγλικά.
- Βαθμολογεί με `0.6·συνάφεια + 0.25·ποιότητα + 0.15·επικαιρότητα`. Η επικαιρότητα μετριέται ως προς το έτος αναφοράς.
- Κάθε αποτέλεσμα φέρει την προέλευσή του (μελέτη, έτος, επίπεδο, άδεια, n).

**Planner και τράπεζα ερωτήσεων**:
- Ο planner προσθέτει έως δύο ερωτήσεις `k*` με ισχυρή επικάλυψη, μία ανά μελέτη, και προειδοποίηση για έλεγχο.
- Η τράπεζα ερωτήσεων εμφανίζει και ερωτήσεις του lake.

**Μοντέλο**:
- Οι κατανομές ανά ομάδα (ηλικία, φύλο, μόρφωση, πεμπτημόριο, όπου υπάρχουν) είναι οι στόχοι του μοντέλου κύριων επιδράσεων (σχήμα `lake`).
- Η αβεβαιότητα παραμένει: τα n των κελιών μεταφέρονται, και η απόκλιση του fit αναφέρεται ρητά.

**Χρονικός κανόνας** (`plan.referenceYear`):
- Δεν χρησιμοποιείται κανένα κύμα με έτος συλλογής μεταγενέστερο του έτους αναφοράς.
- Αν το έτος αναφοράς προηγείται της βαθμονόμησης του πληθυσμού (2025), χρησιμοποιείται ο ιστορικός πληθυσμός βάσης (GLOPOP-S 2015), με σημείωση στην αναφορά.

**Holdout** (`plan.holdoutDatasets`):
- Οι μελέτες αξιολόγησης εξαιρούνται από τη βαθμονόμηση, μαζί με τα διπλότυπα και τα παράγωγά τους:
  - ίδιο κλειδί τίτλου και έτους;
  - συνδεδεμένα διπλότυπα;
  - για holdout Eurobarometer, τα κύματα του ίδιου έτους στα παράγωγα σύνολα NORAYA.

**Προέλευση ανά παράμετρο** (`run.provenance`):
- Για κάθε παράμετρο καταγράφονται:
  - ερώτηση και επιλογή;
  - μελέτη και κύμα;
  - παρατηρημένη τιμή και n;
  - διαστάσεις;
  - επίπεδο, ποιότητα, άδεια και URL;
  - απόκλιση fit.
- Οι παράμετροι που εξαιρέθηκαν καταγράφονται με τον λόγο αποκλεισμού.
- Η αναφορά έχει ενότητα «Προέλευση παραμέτρων». Χωρίζει παρατηρήσεις, παραδοχές του ερευνητή και συνθετικά αποτελέσματα.

**Άδειες**:
- `tier=open` μόνο με ρητά ανοικτή άδεια.
- Με `SYNTHETIC_LAB_LICENSE_MODE=commercial` φορτώνονται μόνο ανοικτές μελέτες.

## 6. Εκτέλεση

```bash
cd scripts/synthetic-lab
python -m venv .venv && .venv/bin/pip install -r lake/requirements.txt
PY=.venv/bin/python lake/run_all.sh            # πλήρης συλλογή (ώρες· επανεκκινήσιμη)
.venv/bin/python -m lake.pipeline status        # σύνοψη καταστάσεων και ουράς
.venv/bin/python -m lake.pipeline monitor       # νέες εκδόσεις Eurostat, νέα Eurobarometer/εγγραφές → ουρά
.venv/bin/python -m lake.pipeline export        # εξαγωγή για το engine
.venv/bin/python -m lake.pipeline report        # reports/coverage_report.{md,json}
.venv/bin/python -m unittest lake.test_lake     # unit tests (χωρίς δίκτυο)
```

Ανεξάρτητα βήματα: `python -m lake.pipeline {discover|run} {eurostat|eurobarometer|eurobarometer_c|repos|catalogs|worldbank|existing}`.
Η επανεκτέλεση συνεχίζει από την ουρά και τα checkpoints. Τα αρχεία που υπάρχουν ήδη δεν κατεβαίνουν ξανά.

Tests του engine: `npx vitest run tests/synthetic-lab/lake.test.ts` (τεχνητό lake) και `lake-real.test.ts`
(πραγματικό τοπικό lake· παραλείπεται αν δεν υπάρχει).

| ΕΚΤ/SoDaNet | Το αποθετήριο δεν ήταν προσβάσιμο από το περιβάλλον συλλογής. Η κάλυψη μεταδεδομένων έρχεται μέσω CESSDA |

| ΕΛΣΤΑΤ | Οι έρευνες διαβιβάζονται στη Eurostat και συλλέγονται από εκεί. Τα microdata δίνονται κατόπιν αίτησης |
| ΙΟΒΕ, ΙΝΕ ΓΣΕΕ, ΙΜΕ ΓΣΕΒΕΕ, διαΝΕΟσις, ΤτΕ | Δημοσιεύσεις PDF χωρίς API. Τα ανοικτά σκέλη (EC BCS/ΙΟΒΕ, διαΝΕΟσις) είναι ήδη ενσωματωμένα |
| OpenAlex | Περιορισμός ρυθμού (429). Η ανακάλυψη datasets γίνεται μέσω OpenAIRE/Crossref |

## 8. Περιορισμοί

- Τα aggregates δίνουν ποσοστά ανά **μία** διάσταση κάθε φορά. Οι αλληλεπιδράσεις διαστάσεων είναι υπόθεση του μοντέλου.
- Οι ερωτήσεις Eurobarometer είναι στα αγγλικά. Η ελληνική διατύπωση του πεδίου μπορεί να διαφέρει.
- Τα έτη των παλαιών Flash Eurobarometer χωρίς πεδίο «Fieldwork» εκτιμώνται από τον αριθμό της έρευνας και σημειώνονται.
- Τα δεδομένα των αποθετηρίων (Zenodo κ.λπ.) είναι συχνά δείγματα ευκολίας. Βαθμολογούνται χαμηλότερα και σημειώνονται ως `convenience`.
