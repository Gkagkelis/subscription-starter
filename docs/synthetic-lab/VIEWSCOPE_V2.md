# Viewscope v2 — οδηγός ενεργοποίησης (προαιρετική έκδοση `viewscope-2.0`)

ΣΥΝΘΕΤΙΚΗ ΠΡΟΣΟΜΟΙΩΣΗ — ΟΧΙ ΠΡΑΓΜΑΤΙΚΗ ΕΡΕΥΝΑ ΠΕΔΙΟΥ.

**Η παραγωγική προεπιλογή ΔΕΝ αλλάζει.** Τα `runSurvey`, PIE, EGPS, prod-1 και structured-1.0 λειτουργούν όπως πριν. Η v2
ενεργοποιείται **μόνο** ρητά, μέσω του runner ή του CLI. Ο υπάρχων μηχανισμός τρέχει αμετάβλητος από κάτω.

## Γρήγορη χρήση

```bash
# 1) (προαιρετικό) συνδέσεις κοινού συνθετικού ανθρώπου για τη μελέτη — τοπικά embeddings, 0 API
python3 -I scripts/synthetic-lab/viewscope/build_core_links.py --plan <study.json|plan.json> --out links.json

# 2) εκτέλεση v2
node_modules/.bin/tsx scripts/synthetic-lab/viewscope/run_study.ts --plan <study.json|plan.json> --n 500 \
   --org "<φορέας ερωτηματολογίου>" --fieldwork-start <ΕΕΕΕ-ΜΜ-ΗΗ> --published-waves \
   [--crosswalks] [--core --core-links links.json [--apply-scenario]] [--out αποτέλεσμα.json] [--save]
```

Χωρίς σημαίες, η v2 προσθέτει μόνο:

- ταξινόμηση E/T/S ανά ερώτηση·
- τους **τρεις δείκτες κάλυψης**: τεχνική, εμπειρική, επικυρωμένη·
- τον **χωριστό πολιτικό διαχωρισμό** (εθνικά ποσοστά / υποομάδες ως S).

Προγραμματιστικά: `runViewscope({...})` από το `lib/synthetic-lab/viewscope/runner.ts`.

## Τι ενεργοποιεί κάθε σημαία

| Σημαία | Λειτουργία | Κατηγορία | Επικύρωση |
|---|---|---|---|
| `--published-waves` | Προηγούμενο δημοσιευμένο κύμα της ίδιας ερώτησης, ίδιου φορέα (χρονικός φραγμός = `--fieldwork-start`, ≤ 24 μήνες) | **T** | Ιστορική: MAE 1,38 π.μ. (41 ζεύγη 2025–09/2026)· η μελλοντική εκκρεμεί |
| `--other-org` | Το ίδιο, από άλλον φορέα | T | Μη επικυρωμένη: μόνο συμπληρώνει αποχές/S |
| `--crosswalks` | Εγκεκριμένοι ρητοί πίνακες αντιστοίχισης προς άγκυρες PIE (`config/.../crosswalks.json`) | T / S | Μόνο αναδρομική |
| `--core` + `--core-links` | Κοινός συνθετικός άνθρωπος: συνεπής ανάθεση απαντήσεων στα πρόσωπα (το συνολικό ποσοστό μένει ίδιο) | δομή T | Πολιτικός, κοινωνικός και καταναλωτικός σε έρευνες ελέγχου· ο οικονομικός ανενεργός |
| `--xtab` [`--xtab-links q.json`] | **vs-xtab-1.0**: επαληθευμένοι δημοσιευμένοι πίνακες υποομάδων (προηγούμενη ψήφος 2023, ιδεολογία, ηλικία, φύλο) ως πιθανοτικές συνθήκες· συμφιλίωση IPF· όρια: ≤ 24 μήνες, απόκλιση ≤ 6 π.μ. | δομή T· σχέση μέσα στις ομάδες S | ESS10→ESS11: σφάλμα συσχετίσεων −0,009, σωστό πρόσημο 49%→74–76%, υποομάδες καλύτερες |
| `--declared σχέσεις.json` | Δηλωμένες σχέσεις S (ήπια 0,15 / μέτρια 0,30) για ερωτήσεις σεναρίου, με ευαισθησία | S | Σενάριο, όχι μέτρηση |
| `--apply-scenario` | Ο πυρήνας εφαρμόζεται και σε σενάρια S του υπάρχοντος μηχανισμού | περιθώριο S | Όπως ο πυρήνας |

**Κανόνας προτεραιότητας.** Κερδίζει η διαδρομή με το μικρότερο **μετρημένο** σφάλμα. Μη επικυρωμένες διαδρομές συμπληρώνουν
μόνο αποχές ή σενάρια.

**Μορφές χωρίς επικυρωμένη διαδρομή** (κατάταξη, ανοιχτές ερωτήσεις, τιμές κ.λπ.): εμφανίζονται **μόνο ως S**. Αυξάνουν την
τεχνική κάλυψη, ποτέ την εμπειρική ή την επικυρωμένη.

Οι πίνακες υποομάδων χτίζονται με `python3 -I scripts/synthetic-lab/viewscope/build_crosstabs.py` (→ `<data>/viewscope/crosstabs.json`). Παράδειγμα δηλωμένης σχέσης: `[{"questionId":"q2","driver":"econ4","direction":1,"strength":"mild"}]` (drivers: econ4, inc6, age, edu, gender, lr7, class3, polint4).

## Δεδομένα και ρυθμίσεις

**Μητρώα και ρυθμίσεις:**

- Μητρώο δημοσιευμένων κυμάτων: `<data>/viewscope/published_waves.json`. Είναι ιδιωτικό και χτίζεται με `scripts/synthetic-lab/viewscope/build_published_waves.py`.
- Μητρώο διαδρομών και επικυρώσεων: `config/synthetic-lab/viewscope/routes.json`.
- Καραντίνα συνόλων δεδομένων: `config/synthetic-lab/viewscope/dataset-quarantine.json` (BankSat).
- Κοινός πυρήνας: `config/synthetic-lab/viewscope/core.json`.

**Έλεγχοι ακεραιότητας:**

```bash
python3 -I scripts/synthetic-lab/viewscope/verify_step.py --step N
```

Ελέγχει:

- hashes προστατευμένων αρχείων·
- αποτυπώματα επανεκτέλεσης·
- κλειδωμένες προβλέψεις 7A·
- πολιτική αξιολόγηση·
- όλα τα τεστ.

## Τι ΔΕΝ κάνει η v2

- Δεν αλλάζει κανένα υπάρχον μοντέλο, μελέτη ή κλειδωμένη πρόβλεψη.
- Δεν εμφανίζει πολιτικές διαφορές υποομάδων ως πρόβλεψη· εμφανίζονται μόνο ως S.
- Δεν χρησιμοποιεί το BankSat για ατομικές σχέσεις.
- Δεν καλεί API.
