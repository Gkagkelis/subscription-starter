## 2. Source-population validation (held-out ερωτώμενοι)

**Πρωτόκολλο (ίδιο για όλα)**

- Ντετερμινιστικός διαχωρισμός **ανά ερωτώμενο**: 60% train / 20% validation / 20% test.
- Τέσσερα μοντέλα σε κάθε dataset: μερίδια πλειοψηφίας, logit μόνο τιμής, conditional logit, mixed logit.
- Επιλογή **μόνο** με βάση το validation log loss· **μία** αξιολόγηση στο test.
- Διαστήματα 95% με bootstrap ανά ερωτώμενο (1.000 επαναλήψεις).
- Χαμηλότερο log loss, Brier και ECE είναι καλύτερο.

**Ερμηνεία για τα ελβετικά μοντέλα**

Οι ερωτώμενοι επέλεγαν σχεδόν αποκλειστικά βάσει περιβαλλοντικών και τεχνικών χαρακτηριστικών και σχεδόν αγνοούσαν την τιμή. Σε αυτό συμβάλλουν τρία πράγματα:

- το πείραμα είναι υποθετικό·
- δεν υπάρχει επιλογή «κανένα»·
- τα επίπεδα τιμής ήταν πλήρως τυχαία, ώστε συνδυάζονταν ακόμη και με την κλάση G.

Τα μοντέλα **προβλέπουν καλά ποιο από δύο νέα προϊόντα θα διαλέξει ένας Ελβετός ερωτώμενος του πάνελ**. Η **απόκρισή τους στην τιμή όμως δεν είναι αξιόπιστη** για τιμολογιακά σενάρια. Η κατάταξη των χαρακτηριστικών (επισκευασιμότητα, ενεργειακή κλάση, διάρκεια) είναι πιο αξιόπιστη από τα επίπεδα WTP.

## 6. Έλεγχος μεταφοράς με πραγματικά δεδομένα

Εκτέλεση με `python3 -I cce_cli.py transfer_check`· αποτελέσματα στο `artifacts/checks/transfer_swiss_wm.json`.

**Πώς έγινε ο έλεγχος**

- CL εκτιμημένο σε **2.295 ερωτώμενους smartphone + TV** εφαρμόστηκε σε **224 held-out ερωτώμενους πλυντηρίων**· ίδιο test με το artifact.
- Τιμή και διάρκεια ως λόγος προς τον μέσο όρο επιπέδων κάθε προϊόντος.

**Αποτελέσματα στο test πλυντηρίων**

| Μοντέλο | Τοπικοί ερωτώμενοι πλυντηρίων | Test log loss |
|---|---|---|
| CL μόνο σε πλυντήρια (όλο το train) | 671 | 0,473 |
| Μεταφορά από smartphone+TV, χωρίς τοπικά δεδομένα | 0 | 0,478 (διαφορά +0,005 [−0,010, +0,019]) |
| Μεταφορά + τοπική κλίμακα/σταθερά | 25 / 50 / 100 / 200 / 400 | 0,497 / 0,487 / 0,482 / 0,481 / 0,480 |
| CL μόνο σε n τοπικούς | 25 / 50 / 100 / 200 / 400 | 0,646 / 0,515 / 0,494 / 0,479 / 0,476 |

(20 επαναλήψεις ανά n)

**Ερμηνεία**

- **Μέσα στον ίδιο πληθυσμό και στο ίδιο ερωτηματολόγιο**, η μεταφορά σε άλλη κατηγορία συσκευής χάνει ελάχιστα.
- Με ≤ 100 τοπικούς ερωτώμενους, ένα μεταφερμένο μοντέλο προβλέπει καλύτερα από ένα τοπικό.
- Περίπου από 200 τοπικούς ερωτώμενους και πάνω, το τοπικό μοντέλο φτάνει ή ξεπερνά το μεταφερμένο.
- Η επανεκτίμηση μόνο κλίμακας σε μικρό τοπικό δείγμα **δεν** βελτίωσε τη σκέτη μεταφορά.

**Όριο:** αυτό είναι **κάτω όριο** της απώλειας μεταφοράς. Η μεταφορά από Ελβετία ή ΗΠΑ στην Ελλάδα αλλάζει πληθυσμό, εισόδημα, νόμισμα, εποχή και ερωτηματολόγιο ταυτόχρονα. **Δεν μετρήθηκε και δεν μπορεί να μετρηθεί χωρίς ελληνικά δεδομένα.**
