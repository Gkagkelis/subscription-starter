# CCE 0.1 — Απογραφή δεδομένων (DATA_INVENTORY)

Ημερομηνία: 2026-10-30. Αφορά τη **Consumer Choice Engine (CCE 0.1)** στον φάκελο `models/consumer-choice-engine/`.

Το κριτήριο είναι ένα: **μπορεί ένα σύνολο δεδομένων να εκπαιδεύσει μοντέλο ατομικών επιλογών;** Αυτό χρειάζεται τρία πράγματα:

1. πραγματικές επιλογές συγκεκριμένων ανθρώπων·
2. εναλλακτικές με χαρακτηριστικά που μεταβάλλονται (τιμή, εγγύηση κ.λπ.)·
3. ατομικά δεδομένα (microdata), όχι συγκεντρωτικά ποσοστά.

Ένα δημοσιευμένο ποσοστό προτίμησης δεν αρκεί.

### Γ. Ελληνικά δεδομένα ατομικών επιλογών

**Δεν βρέθηκε κανένα** ανοιχτό ελληνικό σύνολο πραγματικών ατομικών επιλογών για επισκευή, αντικατάσταση, refurbished, trade-in, εγγύηση ή παράδοση συσκευών. Υπάρχουν ελληνικά microdata ερευνών (Eurobarometer στο GESIS, ELSTAT HBS), αλλά:

- δεν περιέχουν μεταβαλλόμενα χαρακτηριστικά εναλλακτικών·
- απαιτούν εγγραφή ή αίτηση, που δεν έγινε για λογαριασμό του χρήστη.

Βλ. DATA_SOURCES.md και DATA_GAPS.md.
