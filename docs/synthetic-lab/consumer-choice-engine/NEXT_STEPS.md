## Τεχνικές βελτιώσεις του κώδικα (χωρίς νέα δεδομένα)

- Latent class ως τρίτος candidate, όταν υπάρχουν ελληνικά covariates.
- Αναλυτικό Hessian στο mixed logit· σήμερα είναι αριθμητικό. Σε μία περίπτωση (smartphone, `repair_limited`) η τυπική απόκλιση συγκλίνει στο 0 με τεράστιο SE: είναι αδιάφορο για την πρόβλεψη, αλλά πρέπει να επισημαίνεται αυτόματα.
- Αυτόματος έλεγχος αληθοφάνειας WTP (π.χ. WTP > τιμή προϊόντος → σημαία) μέσα στο `cce.check`.

## Τι ΔΕΝ πρέπει να γίνει

- Χρήση των ελβετικών ή αμερικανικών artifacts ως ελληνικών ευρημάτων ή σε παρουσίαση πελάτη χωρίς τη σήμανση `SOURCE_POPULATION_ONLY`.
- Βαθμονόμηση σε δημοσιευμένα ποσοστά για να «ταιριάξουν» τα αποτελέσματα.
- Εμπορική χρήση του refurbished artifact χωρίς άδεια των δημιουργών.
