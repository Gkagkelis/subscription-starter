## A. Persona Architecture Audit — πώς δημιουργείται σήμερα ένας συνθετικός άνθρωπος

Ελέγχθηκε ο πραγματικός κώδικας (`lib/synthetic-lab/persona/*`), όχι η τεκμηρίωση.

```
βαθμονομημένος πληθυσμός (GLOPOP-S, βάρη ηλικία × φύλο × μόρφωση ανά περιφέρεια)
  → επιλογή N προσώπων (PPS με τα βάρη· ακριβώς N)
  → Στάδιο Α: άγκυρες με αλυσίδα μοντέλων (απασχόληση → εισόδημα → «τα βγάζω πέρα» → τάξη → αριστερά–δεξιά
              → προηγούμενη ψήφος → θρησκευτικότητα → ενδιαφέρον για πολιτική), εκτιμημένες σε μικροδεδομένα
  → προσωπικός σπόρος → λανθάνοντα χαρακτηριστικά θ ανά μπαταρία ερωτήσεων (σταθερά για το πρόσωπο)
  → Στάδιο Β: κάθε ερώτηση απαντάται από το πρόσωπο
        ordinal: y* = η(δημογραφικά, άγκυρες) + λ·θ_μπαταρίας + √(1−λ²)·ε  → κατηγορία
        nominal: πολυωνυμικό logit · ψήφος: conditional logit (σενάριο κομμάτων = γεγονότα)
  → ατομικές απαντήσεις (αποθηκεύονται) → σταθμισμένα σύνολα και διασταυρώσεις, μόνο από αυτές
```

### Τι μένει σταθερό, τι αλλάζει

| Χαρακτηριστικό | Σταθερό ανά πρόσωπο | Αλλάζει ανά έρευνα (νέος σπόρος) | Επηρεάζεται από ερωτήσεις |
|---|---|---|---|
| Δημογραφικά (ηλικία, φύλο, μόρφωση, περιοχή, αστικότητα) | ναι | νέο δείγμα | όχι |
| Άγκυρες (απασχόληση, εισόδημα, οικονομική κατάσταση, αριστερά–δεξιά, ψήφος 2023, θρησκευτικότητα, ενδιαφέρον) | ναι | νέο δείγμα | όχι |
| Λανθάνοντα θ ανά μπαταρία | ναι (από τον προσωπικό σπόρο) | νέο δείγμα | όχι |
| Ψήφος | ναι (pie-runtime-2): ίδια όσο δεν αλλάζει το σενάριο | νέο δείγμα | όχι |
| Θόρυβος απάντησης ε | όχι | ναι | — |
| Ερωτήσεις συνέχειας | — | — | ναι (`followUpOf`, pie-runtime-2) |

Ο θόρυβος ε είναι η «αβεβαιότητα του πραγματικού ανθρώπου».

### Προέλευση των στοιχείων

| | Περιεχόμενο |
|---|---|
| **Από πραγματικά δεδομένα** | περιθώρια, συντελεστές δημογραφικών και αγκυρών, φορτίσεις μπαταριών (ατομικά δεδομένα διαΝΕΟσις, CSES, MAPLE, UNDPOLAR), μοντέλο ψήφου (CSES), αποχή/αναποφάσιστοι (MAPLE 2019) |
| **Εμπειρικά μαθημένες σχέσεις** | δημογραφικά ↔ άγκυρες ↔ απαντήσεις· συσχετίσεις μέσα σε μπαταρία |
| **Υποθέσεις** | σταθερότητα σχέσεων στον χρόνο· ισοδυναμία συγγενικών ερωτήσεων· θέσεις νέων κομμάτων (σενάριο)· καμία σχέση μεταξύ ερωτήσεων από **διαφορετικές πηγές** πέρα από τα κοινά δημογραφικά και τις άγκυρες |

| # | Σφάλμα | Συνέπεια | Διόρθωση και έλεγχος |

## B. Behavioral Consistency Report

Η μετρική είναι το σφάλμα συσχέτισης R1: μέσο |ρ_syn − ρ_real| σε ζεύγη αντιστοιχισμένων ερωτήσεων και αγκυρών.

| Σύνολο | Ρόλος | Ανεξάρτητες απαντήσεις (B_ind) | pie-0.3 | **pie-0.4 (E1)** | Πρόσημο R2 (0.3 → 0.4) | Δεσμευμένη απόκλιση R3 (0.3 → 0.4) |
|---|---|---|---|---|---|---|
| DEMOTEC 2022 (online) | επιλογή | 0,264 | 0,166 | **0,131** | 0,958 → 0,958 | 0,068 → 0,067 |
| ESS10 (CAPI) | επιλογή | 0,253 | 0,184 | **0,166** | 0,853 → 0,853 | 0,026 → 0,026 |
| **LiTS IV 2022–23** | επιβεβαίωση, μία φορά | — | 0,166 | **0,138** | 0,901 → 0,915 | 0,026 → 0,027 |
| **ISSP 2023** | επιβεβαίωση, μία φορά | — | 0,186 | **0,181** | 0,895 → 0,842 | 0,035 → 0,034 |
| K1 + K2 μαζί (133 ζεύγη) | επιβεβαίωση | | | διαφορά −0,024, 80% CI [−0,028, −0,020] | | |

Το σφάλμα R3 μετριέται σε μονάδες ridit.

**Συνοχή λανθάνοντος, μπαταρία εμπιστοσύνης LiTS (10 θεσμοί):**

| | Μέση συσχέτιση | Cronbach α |
|---|---|---|
| Πραγματικό | 0,455 | 0,89 |
| pie-0.3 | 0,229 | 0,75 |
| pie-0.4 | 0,304 | 0,81 |

**Αναπαράγονται σωστά (|σφάλμα| < 0,10, περίπου 40–47% των ζευγών):**
- σχέσεις με τις άγκυρες: ιδεολογία, οικονομική κατάσταση, ενδιαφέρον;
- μέτριες σχέσεις μέσα σε μπαταρία, π.χ. δικαστήρια–κόμματα 0,35/0,35 και κοινωνική εμπιστοσύνη–ιδεολογία 0,14/0,10;
- οι πρακτικά μηδενικές σχέσεις, π.χ. κοινωνική εμπιστοσύνη–πρόσφυγες.

**Δεν αναπαράγονται ακόμη:**
- **Πολύ ισχυρές σχέσεις μέσα σε μπαταρία:** υποεκτιμώνται ακόμη, παρά τη βελτίωση. Κυβέρνηση–Βουλή: πραγματικό 0,80, από 0,37 στο 0,46. Βουλή–κόμματα: 0,74, από 0,33 στο 0,43.
- **Σχέσεις μεταξύ ερωτήσεων από διαφορετικές πηγές:** σχεδόν μηδενικές στα πρόσωπα. Ικανοποίηση από τη δημοκρατία (CSES) ↔ εμπιστοσύνη (διαΝΕΟσις): πραγματικό 0,49–0,73, πρόσωπα 0,05–0,13. Λαϊκισμός (UNDPOLAR) ↔ πολιτική αποτελεσματικότητα (διαΝΕΟσις): 0,37 έναντι ~0.
- **Κυβέρνηση × ιδεολογία:** πραγματικό +0,50, πρόσωπα ≈ 0, όταν η πηγή είναι από άλλη κυβερνητική περίοδο. Βλ. E3 στο F.

**Γιατί απέτυχε το E2.** Το κοινό λανθάνον ανά έννοια (E2) δεν μπορεί να καλύψει τις σχέσεις μεταξύ πηγών. Δεν υπάρχουν πραγματικά δεδομένα όπου οι δύο ερωτήσεις συνυπάρχουν, και το σύστημα σωστά δεν επινοεί σχέση.

## C. Sample Size Tests

Χρησιμοποιήθηκε το πραγματικό runtime, με ερωτηματολόγιο μικτό (πολιτικό, κοινωνικό, καταναλωτικό), μία ερώτηση συνέχειας, μία πολλαπλής επιλογής και ερωτήσεις Cinobo. Κάθε N έτρεξε με 5 σπόρους, για τις pie-0.2, pie-0.3 και pie-0.4.

| Έλεγχος | N = 100 | 200 | 500 | 1.000 |
|---|---|---|---|---|
| Ακριβές N / μοναδικά ID | ✓ / ✓ | ✓ / ✓ | ✓ / ✓ | ✓ / ✓ |
| Μοναδικά προφίλ (δημογραφικά + άγκυρες) | 92% | 92% | 84% | 73% |
| Μοναδικά πλήρη διανύσματα απαντήσεων | 100% | 100% | ≥99,4% | ≥99,6% |
| Σύνθεση: TVD μόρφωσης, παλιά επιλογή | 9,3% | 7,7% | 9,4% | **9,2%** |
| Σύνθεση: TVD μόρφωσης, PPS | 7,2% | 6,0% | 2,8% | **1,7%** |
| Μέγιστη διαφορά ατομικών–συνόλων (π.μ.) | 0,05 | 0,05 | 0,05 | 0,05 |
| Παραβιάσεις κανόνων παράλειψης / πολλαπλής επιλογής | 0 / 0 | 0 / 0 | 0 / 0 | 0 / 0 |
| Απαντήσεις σε «δεν εκτιμάται» (Cinobo) | 0 | 0 | 0 | 0 |
| Άθροισμα ομάδων διασταυρώσεων = N | ✓ | ✓ | ✓ | ✓ |
| SD μεταξύ σπόρων, «ΝΔ» στην πρόθεση (pie-0.4, π.μ.) | 2,9 | 2,7 | 1,8 | **0,8** |
| Μέση συσπείρωση ΝΔ (pie-0.4) | 59% | 60% | 60% | **60%** |
| Μέση συσπείρωση ΝΔ (pie-0.2) | 45% | 50% | 52% | **50%** |

- Η επανάληψη προφίλ στα μεγάλα N είναι αναμενόμενη: λίγες κατηγορίες ανά χαρακτηριστικό. Τα πλήρη πρόσωπα πάντως δεν είναι αντίγραφα.
- Οι δημοσκοπήσεις 2026 δίνουν συσπείρωση ΝΔ 58–65%.
- **Συμπέρασμα:** το μεγαλύτερο N μειώνει τη δειγματοληπτική διακύμανση περίπου ως 1/√N. **Δεν** μειώνει το συστηματικό σφάλμα του μοντέλου, π.χ. η pie-0.2 μένει στο 50% συσπείρωση ΝΔ με όσα πρόσωπα κι αν τρέξει. Μεγαλύτερο συνθετικό N **δεν** σημαίνει μεγαλύτερη πραγματική ακρίβεια.

**Μόνιμο panel** (ίδια πρόσωπα, δεύτερη εκτέλεση):
- Οι άγκυρες μένουν 100% ίδιες.
- Η ψήφος μένει 100% ίδια, αφού το σενάριο δεν αλλάζει (pie-runtime-2).
- Η ίδια απάντηση σε ερωτήσεις στάσεων επαναλαμβάνεται στο 55–69%, που είναι ρεαλιστικός θόρυβος μέτρησης.

**Δεν είναι πραγματικό longitudinal panel.** Δεν μοντελοποιείται καμία μεταβολή στον χρόνο εκτός από αλλαγή σεναρίου.

## F. Remaining Limitations — πού μπορούμε να δώσουμε εκτίμηση

| Κατηγορία | Τι περιλαμβάνει | Χειρισμός |
|---|---|---|
| **Τεκμηριωμένη εκτίμηση** (DIRECTLY_SUPPORTED) | Ίδια ερώτηση με πρόσφατη πηγή: εμπιστοσύνη σε θεσμούς, κοινωνικές αξίες, τρόπος ζωής από διαΝΕΟσις 2023, αυτοτοποθέτηση, προηγούμενη ψήφος, οικονομική κατάσταση νοικοκυριού. Σχέσεις μέσα στην ίδια μπαταρία και με δημογραφικά/άγκυρες. | — |
| **Χαμηλή εμπιστοσύνη** (MODEL_EXTRAPOLATED) | Πρόθεση ψήφου (ΚΚΕ, ΣΥΡΙΖΑ, νέα κόμματα)· συγγενικές ερωτήσεις (επίπεδο συχνά χειρότερο από ομοιόμορφη κατανομή)· ενδιαφέρον για την πολιτική (εξάρτηση από διατύπωση)· ερωτήσεις κυβέρνησης από άλλη κυβερνητική περίοδο (E3)· σχέσεις μεταξύ ερωτήσεων από διαφορετικές πηγές | προειδοποίηση στην αναφορά |
| **«Δεν εκτιμάται αξιόπιστα»** | Brand/NPS/γνωριμία (Cinobo κ.λπ.), σημαντικότερα προβλήματα, κατεύθυνση χώρας, αντιπολίτευση, αρχηγοί, ό,τι δεν έχει ατομικά δεδομένα | καμία συνθετική απάντηση |

## G. Release Recommendation

**Πρόταση: pie-0.4** για παραγωγική χρήση, μετά από ρητή έγκριση. Μέχρι τότε η pie-0.2 μένει προεπιλογή.

**Γιατί:**
- Είναι η μόνη έκδοση με βελτίωση στις σχέσεις μεταξύ απαντήσεων **επιβεβαιωμένη σε δύο ανέγγιχτες έρευνες**.
- Κρατά το καλύτερο μοντέλο ψήφου (C4a).
- Δεν χειροτερεύει στα περιθώρια.

**Περιορισμοί:** όσα αναφέρονται στο F. Τα πολιτικά αποτελέσματα να συνοδεύονται πάντα από την προειδοποίηση για ΚΚΕ/ΣΥΡΙΖΑ/νέα κόμματα.

**Ενεργοποίηση** (μόνο από άνθρωπο):
```
python3 scripts/synthetic-lab/persona/registry.py approve --version pie-0.4 --by "<όνομα>"
```
Δοκιμή χωρίς ενεργοποίηση: `plan.personaModelVersion = 'pie-0.4'`.

**Rollback:** `registry.py reject --version pie-0.4`. Οι pie-0.2 και pie-0.3 μένουν ανέπαφες.
