# Phase 6 — Ταυτοποιησιμότητα ενός κοινού λανθάνοντος ελληνικού πληθυσμιακού μοντέλου

**Σενάρια:**
- `gpm_matrix.py`: πίνακας GRIM v1·
- `gpm_identify.py`: ανάλυση.

**Αποτελέσματα:** `.synthetic-lab-data/gpm/v1/identify.json` (ιδιωτικό).

**Ερώτημα Stage 0:** επιτρέπουν τα υπάρχοντα ελληνικά ατομικά δεδομένα έναν **κοινό** λανθάνοντα χώρο για όλους τους τομείς;

**Σύντομη απάντηση: όχι πλήρως.**
- Ένας κοινός χώρος ταυτοποιείται **μέσα** σε κάθε έρευνα και **μεταξύ** ερευνών που μοιράζονται τις ίδιες ερωτήσεις.
- Οι συσχετίσεις μεταξύ εννοιών που **ποτέ** δεν μετρήθηκαν μαζί δεν ταυτοποιούνται αξιόπιστα, ούτε μέσω αλυσίδων.

## 6. Εγκυρότητα: πρόβλεψη συσχετίσεων σε έρευνα που αφαιρέθηκε

Το κοινό μοντέλο εκτιμάται **χωρίς** την έρευνα-στόχο. Μετά προβλέπει τις συσχετίσεις των ερωτήσεών της. Σφάλμα = μέση |r_πραγματικό − r_μοντέλο|· «Μηδέν» = μοντέλο που προβλέπει ανεξαρτησία.

| Έρευνα | Ζεύγη μετρημένα μαζί αλλού: μοντέλο / μηδέν | Ζεύγη μόνο μέσω αλυσίδας: μοντέλο / μηδέν |
|---|---|---|
| ESS11 | **0,059** / 0,070 | 0,040 / 0,042 |
| διαΝΕΟσις 2017 | **0,062** / 0,114 | **0,080** / 0,105 |
| διαΝΕΟσις 2024a | **0,100** / 0,124 | **0,119 / 0,085, χειρότερο** |
| UNDP 2022 | 0,173 / 0,170 | **0,118 / 0,065, χειρότερο** |
| MAPLE 2019 | 0,093 / 0,074, χειρότερο | **0,120 / 0,093, χειρότερο** |
| EB 103.3 | 0,078 / 0,079 | — |

**Συμπεράσματα:**
1. Όπου ένα ζεύγος έχει μετρηθεί μαζί **κάπου αλλού**, το κοινό μοντέλο μεταφέρει τη σχέση. Το κέρδος είναι μέτριο έως μεγάλο σε ESS και διαΝΕΟσις.
2. Όπου η σχέση προκύπτει **μόνο μέσω αλυσίδας** γεφυρών, το μοντέλο είναι **χειρότερο από την υπόθεση ανεξαρτησίας** σε 3 από 5 έρευνες.
3. **Κανόνας για τον runtime:** δεν εφαρμόζονται διαερευνητικές συσχετίσεις που δεν έχουν μετρηθεί ποτέ μαζί. Εκεί διατηρείται η αβεβαιότητα: ανεξαρτησία υπό συνθήκη των κοινών χαρακτηριστικών.

## 7. Απόφαση Stage 0

| Ερώτημα | Απάντηση |
|---|---|
| Ταυτοποιείται ένα **πλήρες** κοινό λανθάνον μοντέλο όλων των τομέων; | **Όχι** |
| Ταυτοποιείται **μερικό** μοντέλο; | **Ναι**: ανά έρευνα (k ≈ 5–10) και μεταξύ ερευνών με κοινές ερωτήσεις |
| Καταναλωτικές διαστάσεις | **Όχι** (4–9 έρευνες, ελάχιστες ερωτήσεις)· ταυτοποιούνται μόνο ως μεμονωμένες ερωτήσεις |
| Σχέση πολιτικών και καταναλωτικών στάσεων | **Δεν ταυτοποιείται.** Καμία ελληνική έρευνα δεν μετρά ταυτόχρονα πλούσια πολιτική και καταναλωτική συμπεριφορά. |

**Τι υλοποιήθηκε:** το καλύτερο **ταυτοποιήσιμο μερικό** μοντέλο, και αξιολογήθηκε απέναντι στην υπάρχουσα PIE (`PHASE6_RESULTS.md` §B).

**Ποια δεδομένα λείπουν** (`PHASE6_FIELDWORK_BLUEPRINT.md`):
- ένα ελληνικό δείγμα που μετρά **ταυτόχρονα** σταθερές άγκυρες (ιδεολογία, εμπιστοσύνη, οικονομική κατάσταση) **και** καταναλωτικές μονάδες·
- επαναλήψεις του ίδιου δείγματος (panel), ώστε να ταυτοποιηθούν οι σχέσεις και η χρονική μεταβολή.
