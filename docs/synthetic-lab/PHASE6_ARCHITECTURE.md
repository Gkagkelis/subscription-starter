# Phase 6 — Αρχιτεκτονική

Το έγγραφο περιγράφει τι **υπάρχει στον κώδικα** μετά την Phase 6 και ποια συστατικά **δοκιμάστηκαν και απορρίφθηκαν**. Τα αποτελέσματα είναι στο `PHASE6_RESULTS.md`.

## 1. Ροή μιας ερώτησης (runtime, pie-0.7 staged)

```
Ερωτηματολόγιο (ελληνικό, μικτό)
 │
 ├─ offline CLI: iqge.py [--international-lake]   → personaLink.iqge (επίπεδο, τεκμήρια, tier, lake)
 │                                               (S1: GlobalMatcher → ισοδύναμη διεθνής ερώτηση)
 ├─ autolink (TS)                                 → σύνδεση με ίδια ελληνική ερώτηση της τράπεζας
 │
 ▼
prepareQuestion (respond.ts)        support: DIRECTLY_SUPPORTED / MODEL_EXTRAPOLATED / NOT_RELIABLY_ESTIMABLE
 ▼
classifyEvidence (evidence-tier.ts) τομέας → ειδικό μοντέλο → Tier 1–5 → εκτίμηση ή ΑΠΟΧΗ
 │   Tier 1  ίδια ελληνική ερώτηση / άγκυρα / ψήφος με σύγχρονο σενάριο
 │   Tier 3  ισοδύναμη διεθνής ερώτηση (B5)
 │   Tier 4  πειραματικό (S2, ιστορικό σενάριο ψήφου)· μόνο με allowExperimental
 │   Tier 5  αποχή: «Δεν υπάρχει επαρκής εμπειρική τεκμηρίωση… Απαιτείται πραγματική ελληνική βαθμονόμηση.»
 ▼
respondPanel → ατομικές απαντήσεις (ίδιο πρόσωπο σε όλες τις ερωτήσεις· κανόνες παράλειψης)
 ▼
aggregate → ποσοστά + προέλευση + evidenceTier (αναμενόμενο σφάλμα, p90, πηγές, περιορισμοί)
```

## 3. Γιατί δεν υπάρχει «ενιαίο GPM» στον runtime

1. **Ταυτοποιησιμότητα** (`PHASE6_DATA_IDENTIFIABILITY.md`):
   - Ο κοινός χώρος ταυτοποιείται μόνο εντός ερευνών και μεταξύ ερευνών με κοινές ερωτήσεις.
   - Οι σχέσεις «μόνο μέσω αλυσίδας» είναι χειρότερες από την ανεξαρτησία σε 3/5 έρευνες.
2. **Κοινή συμπεριφορά:** στη διαΝΕΟσις 2024 η υπάρχουσα PIE με λανθάνον e1 είχε χαμηλότερο σφάλμα συσχετίσεων από τις GPM personas σε 2 από 3 κύματα. Υπερίσχυσε και στο σύνολο. Ο προκαθορισμένος κανόνας (≥ 10% βελτίωση) δεν ικανοποιήθηκε.
3. **Περιθώρια νέων ερωτήσεων:** το ελληνικό κατώφλι μιας νέας ερώτησης **δεν ταυτοποιείται** χωρίς ελληνικές απαντήσεις. Η πρόβλεψη του «τι μετρά» μια ερώτηση (φορτίσεις) δεν δίνει το επίπεδο.

Η αρχιτεκτονική που μένει:
- **υπάρχουσα PIE**: άγκυρες, ordinal probit ανά ερώτηση, λανθάνοντα μπαταριών·
- **διεθνής μεταφορά** για τυποποιημένες ερωτήσεις·
- **ρητό επίπεδο τεκμηρίωσης** που απέχει όταν τα δεδομένα δεν επαρκούν.

## 4. Διαχωρισμός προβλημάτων (Part B)

| | Πρόβλημα 1: περιθώρια | Πρόβλημα 2: κοινή συμπεριφορά |
|---|---|---|
| Τι καθορίζει την ακρίβεια | ελληνικό επίπεδο της ίδιας (ή ισοδύναμης) ερώτησης | σχέσεις μεταξύ ερωτήσεων, υποομάδες |
| Μετρική | MAE, διάμεσος, p90, κάλυψη | σφάλμα συσχετίσεων ζευγών, δεσμευμένη TVD, ridit υποομάδων, Cronbach, ποικιλία |
| Τελικό τεστ Phase 6 | **H6 (τυφλό)** | μόνο ανάπτυξη· τυφλό τεστ προγραμματισμένο στο ESS12 (1/2027) |
| Πηγές αβεβαιότητας | διεθνής μεταφορά, χρονική μετατόπιση, δειγματοληψία της αλήθειας, τρόπος έρευνας | λανθάνουσα δομή, ταυτοποιησιμότητα |

## 5. Πρόσωπα και ιδιωτικότητα

- Οι συνθετικοί ερωτώμενοι **δεν** αντιγράφουν πραγματικές εγγραφές. Η παραλλαγή D (πραγματικές απαντήσεις δοτών) δοκιμάστηκε μόνο offline και **δεν** ενσωματώνεται, γιατί δεν βελτίωσε τα αποτελέσματα.
- Κάθε έξοδος σημαίνεται «AI-generated synthetic research».
