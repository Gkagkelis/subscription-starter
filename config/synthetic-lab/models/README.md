# Εκδόσεις μοντέλου (πειραματικές)

Αντίγραφα των ρυθμίσεων που αξιολογήθηκαν στο benchmark (`<dataRoot>/benchmarks/models/`), για ιστορικό και επαναφορά. Περιέχουν μόνο παραμέτρους, όχι δεδομένα.
Η παραγωγική έκδοση (`prod-1`) ορίζεται στον κώδικα (`lib/synthetic-lab/engine/model-config.ts`) και **δεν έχει αλλάξει**.

| Έκδοση | Βάση | Τι αλλάζει |
|---|---|---|
| `exp-20261028-a` | prod-1 | αγκύρωση επιπέδου, λανθάνων παράγοντας συστοιχίας ρ=0,3 (φάση 1) |
| `p2-u` | exp-20261028-a | αντιστοίχιση πληθυσμού αναφοράς, επιλογή ερωτώμενων PPS |
| `p2-t-locf` | p2-u | σειρά της ΙΔΙΑΣ ερώτησης (όλα τα προγενέστερα κύματα), τελευταία μέτρηση |
| `p2-t` | p2-t-locf | χρονική πρόβλεψη Kalman ανά οικογένεια πηγών (`temporal_params.calibration.json`) |
| `p2-tx` | p2-t | ακριβής αντιστοίχιση ερώτησης στην ανάκτηση (μετά το holdout2 — αξιολογημένη μόνο στο validation) |

Επαναφορά: οποιαδήποτε έκδοση φορτώνεται με `benchmark.ts run --model <έκδοση>` αφού αντιγραφεί στο `<dataRoot>/benchmarks/models/`.
Η προαγωγή σε παραγωγή γίνεται ΜΟΝΟ με αλλαγή του `PRODUCTION_MODEL` μετά από έγκριση.
