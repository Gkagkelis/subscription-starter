# Ετοιμότητα και εντολή για 500 ολοκληρωμένες συνθετικές συνεντεύξεις

**ΣΥΝΘΕΤΙΚΗ ΠΡΟΣΟΜΟΙΩΣΗ — ΟΧΙ ΠΡΑΓΜΑΤΙΚΗ ΕΡΕΥΝΑ ΠΕΔΙΟΥ.**

> **Η πλήρης εκτέλεση ΔΕΝ έχει ξεκινήσει.** Η μηχανή την αρνείται όσο το `config.yaml` έχει `status: DRAFT_PENDING_PARTNER_APPROVAL` (πύλη έγκρισης· test). Χρειάζεται η ρητή επιβεβαίωσή σας μετά την έγκριση του συνεργάτη.

## 1. Αξιολόγηση ετοιμότητας

| Περιοχή | Κατάσταση | Τεκμήριο |
|---|---|---|
| Ερωτηματολόγιο στη μορφή της μηχανής, χωρίς απώλεια | **Έτοιμο** | `questionnaire.yaml`· round-trip OK |
| Skip logic και διαδρομές | **Έτοιμο** | 10 διαδρομές, καμία απρόσιτη ερώτηση (`QUESTIONNAIRE_VALIDATION.md` §4) |
| Λογικοί περιορισμοί | **Έτοιμο, εκκρεμεί έγκριση** | C1–C5 ικανοποιήσιμοι σε κάθε συνδυασμό· 0 παραβιάσεις σε 500 mock + 12 πιλοτική |
| 500 completes χωρίς άκυρες/αντιφατικές απαντήσεις | **Επαληθεύτηκε τεχνικά** | mock 500 (τελική διάταξη): 500/500, 0 σφάλματα, 0 παραβιάσεις, 100% αναπαραγώγιμο με το ίδιο seed |
| Δημογραφική σύνθεση | **Έτοιμο** | πάνελ GLOPOP-S → Eurostat/ΕΛΣΤΑΤ 2025· μέγιστη απόκλιση 0,6 μονάδες στα 500 |
| Πιλοτική με πραγματικό AI | **Έγινε (v2) + QA διαδρομών** | `GO_NO_GO.md`: καθαρή πιλοτική `pilot_k500_v2` 12/12 με την τρέχουσα έκδοση· `qa_branches` (4 πρόσωπα με ορισμένες πύλες) κάλυψε Q16–Q21 και τον μη γνώστη· και οι 37 ερωτήσεις απαντήθηκαν από πραγματικό AI |
| Συνέχεια μετά από διακοπή / σταδιακή εκτέλεση | **Έτοιμο** | checkpoint + `--resume`· δοκιμή 20 → 40 completes στο ίδιο run, 0 διπλοεγγραφές |
| Πάροχος AI χωρίς πληρωμένο API | **Έτοιμο** | `claude_session`, μη χρεούμενος· απαιτεί `--confirm` (διόρθωση: πριν ζητούσε προϋπολογισμό σε USD και δεν μπορούσε να εκτελεστεί) |
| Ετικέτα συνθετικής μελέτης σε κάθε έξοδο | **Έτοιμο** | tests |
| Audit εκτέλεσης | **Πέρασε** | `ase_cli.py audit-run`: 0 λάθη διαδρομής, 0 παραβιάσεις, 0 αποκλίσεις report, 0 διαρροές Signalyth, κλήρωση εντάξει |
| Tests | **Πέρασαν (66/66)** | `python3 -I research-engine/tests/run_tests.py` |

**Συμπέρασμα:** η μελέτη είναι **τεχνικά έτοιμη**. Εκκρεμούν η έγκριση του ερωτηματολογίου και των προσθηκών της ενοποίησης (§3) και η επιβεβαίωσή σας. Οι επιστημονικοί περιορισμοί της §2 δεν εμποδίζουν την εκτέλεση, αλλά καθορίζουν πώς πρέπει να διαβάζονται τα αποτελέσματα.

## 2. Επιστημονικοί περιορισμοί που παραμένουν

1. **32 από τις 34 ουσιαστικές ερωτήσεις στηρίζονται κυρίως στο AI** (`EVIDENCE_AUDIT.md`).
   - Δεν υπάρχει αντιπροσωπευτική μέτρηση γνωριμίας, εικόνας, εμπιστοσύνης, πελατείας, NPS ή εμπειρίας για τον Κωτσόβολο, ούτε στο ελληνικό lake ούτε σε διεθνείς πηγές.
   - Τα αποτελέσματα είναι **κρίσεις του AI για συνθετικά πρόσωπα**, όχι εκτιμήσεις πληθυσμού.
2. **Τα επίπεδα μάρκας εξαρτώνται από μη μετρημένη βάση.** Η ανάλυση ευαισθησίας (±0,5 / ±1 logit) δείχνει μεγάλες μεταβολές (π.χ. στην πιλοτική η εμπιστοσύνη Q09 κυμαινόταν 19%–53%). Οι **συγκρίσεις μεταξύ ομάδων** είναι πιο αξιόπιστες από τα απόλυτα ποσοστά.
3. **Τα εμπειρικά όρια (Q01/Q02) είναι αδύναμα.** Είναι λογικά έγκυρα αλλά δεν δεσμεύουν. Το πλαίσιο Eurostat (Q14–Q16) αφορά online αγορές γενικά, όχι τη μάρκα.
4. **Καμία επικύρωση των απαντήσεων AI έναντι πραγματικών δεδομένων** για αυτές τις έννοιες. Ο μηχανισμός βαθμονόμησης υπάρχει (`import-real` → `compare` → `calibrate`) και περιμένει πραγματικό δείγμα.
5. **Γνώση του AI για τη μάρκα.** Το μοντέλο μπορεί να «ξέρει» τη δημόσια εικόνα του Κωτσόβολου από τα δεδομένα εκπαίδευσής του. Οι οδηγίες ζητούν κρίση για το πρόσωπο και ουδετερότητα· η επίδραση δεν μπορεί να μηδενιστεί ούτε να μετρηθεί εδώ.
6. **Μεταβλητότητα AI.** Ανεξάρτητες επαναλήψεις για το ίδιο πρόσωπο συμφωνούν μερικώς (78% στην προηγούμενη μελέτη). Συνιστάται επανάληψη σε υποδείγμα 50 προσώπων μετά την εκτέλεση, ώστε να μετρηθεί.
7. **Ασυνέπειες από σπάνιες κληρώσεις.** Μετρώνται με τους κανόνες S1–S14, με όριο QC 10% ανά κανόνα.
8. **Φύλο:** οι επιλογές «Άλλο / μη δυαδικό» και «Προτιμώ να μην απαντήσω» του D02 δεν μπορούν να προκύψουν (δυαδικό πλαίσιο πληθυσμού).
9. **Όχι δειγματοληψία πιθανότητας.** Κανένα περιθώριο σφάλματος. Τα 500 completes δεν «διορθώνουν» μεροληψίες του μοντέλου.
10. **Αναφορά Signalyth.** Δεν χρησιμοποιείται ως δεδομένο. Τα αποτελέσματα μπορεί να διαφέρουν από το social listening: αυτό είναι σκόπιμο, όχι σφάλμα.

## 4. Ρύθμιση και εντολές

Ρύθμιση (υπάρχει ήδη στο `studies/kotsovolos_signalyth_2026_500/config.yaml`):

```yaml
status: DRAFT_PENDING_PARTNER_APPROVAL      # → APPROVED μόνο μετά την έγκριση
panel:
  population: adults_18_plus
  sample_size: 500
  sample_size_basis: completes              # 500 ΟΛΟΚΛΗΡΩΜΕΝΕΣ συνεντεύξεις
  completes: {quota_basis: general_population, max_profiles: 600}
  random_seed: 20261101
llm: {max_tokens: 2000, history_window: 60}
run: {batching: per_block_dep}
lab: {enabled: true, model: pie-0.7, ref: "2026-10", prompt_anchors: [emp, econ4, class3]}
```

Εντολές (από τη ρίζα του repo):

```bash
S=studies/kotsovolos_signalyth_2026_500

# 0) μόνο αν άλλαξε το JSON ή το overlay μετά την έγκριση
python3 -I research-engine/ase_cli.py import-questionnaire $S/source/kotsovolos_500_questionnaire.json $S/questionnaire.yaml --overlay $S/integration_overlay.yaml
python3 -I research-engine/ase_cli.py paths $S
python3 -I research-engine/ase_cli.py evidence-plan $S
python3 -I research-engine/tests/run_tests.py

# 1) έγκριση: στο $S/config.yaml  status: APPROVED

# 2) ΣΤΑΔΙΟ Α — πρώτα 50 completes (σημείο ελέγχου για τους κλάδους που δεν είδε η πιλοτική)
python3 -I research-engine/ase_cli.py run $S --provider claude_session --confirm --n 50 --resume k500_full_v1
#    κύκλος γύρων μέχρι να μη μένουν αιτήματα:
python3 -I research-engine/ase_cli.py session-status $S --run k500_full_v1      # λίστα αιτημάτων pending/
#    … απαντήσεις της συνεδρίας στο $S/internal/runs/k500_full_v1/session/inbox/<key>.json …
python3 -I research-engine/ase_cli.py session-import $S --run k500_full_v1
python3 -I research-engine/ase_cli.py run $S --provider claude_session --confirm --n 50 --resume k500_full_v1
#    έλεγχος: $S/internal/runs/k500_full_v1/quality_checks.json, evidence_coverage.csv, κάλυψη Q16–Q21

# 3) ΣΤΑΔΙΟ Β — συνέχεια ως τα 500 στο ΙΔΙΟ run (οι 50 δεν ξαναγίνονται)
python3 -I research-engine/ase_cli.py run $S --provider claude_session --confirm --resume k500_full_v1
#    ίδιος κύκλος γύρων (session-status → inbox → session-import → run … --resume k500_full_v1)

# 4) παραδοτέα (CSV, HTML/PDF, ευαισθησία, κάλυψη τεκμηρίωσης)
python3 -I research-engine/ase_cli.py report $S --run k500_full_v1
```

Οι απαντήσεις της συνεδρίας δίνονται με τις οδηγίες `reports/SESSION_ANSWERER_BRIEF.md` (ίδιες με την πιλοτική). Συνοπτικά: μόνο `system_prompt.txt` + το αίτημα· κατανομή πιθανοτήτων ανά επιλογή· ουδετερότητα για τη μάρκα· έλεγχος με το schema πριν από την εγγραφή.
